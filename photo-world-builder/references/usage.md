# Start with photos · 从照片开始 · 写真からはじめる

## 中文

下载并解压 skill 后，让 Codex 读取其中的 `SKILL.md`。也可把 `photo-world-builder` 文件夹安装到 `~/.codex/skills/`，用 `$photo-world-builder` 调用。

**现在就可以在这里上传 1–6 张照片**，然后发：

> 用照片小世界模板，根据这些照片搭建我的小世界。我最想保留的细节是：____。

名字和风格暂时没想好也可以，一张照片就能开始。

“这里”指 Codex 对话。网页提供试玩和指南，照片制作在 Codex 中完成。可以补充“用英文／日文交付”。试玩后继续在同一个项目修改，保留世界 ID 与存档。

## English

Unzip the skill and ask Codex to read its `SKILL.md`. Alternatively, install the `photo-world-builder` folder in `~/.codex/skills/` and invoke `$photo-world-builder`.

**Upload 1–6 photos in your Codex conversation**, then send:

> Use the Photo World Builder template to build my little world from these photos. The detail I most want to keep is: ____.

No name or style in mind yet? That is fine. One photo is enough to begin.

The website is a guide and playable demo. Photo interpretation and creation happen in Codex. Choose 中文, English or 日本語 in the finished world. Continue editing the same project to preserve its ID and save.

## 日本語

skill を解凍して、`SKILL.md` を Codex に読み込んでもらいます。`photo-world-builder` フォルダーを `~/.codex/skills/` に入れ、`$photo-world-builder` で呼び出すこともできます。

**Codex の会話に写真を1〜6枚添付して**、こう送ってください：

> 写真の小さな世界テンプレートを使って、この写真から自分の世界を作ってください。いちばん残したい特徴は：____。

名前やスタイルが決まっていなくても大丈夫。写真1枚から始められます。

サイトはガイドと体験版です。写真の確認と制作は Codex で行います。完成した世界は中文・English・日本語を選べます。続きは同じプロジェクトを編集し、ID と保存データを維持してください。
